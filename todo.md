Тестовое задание для Bitrix-разработчика
Привет! 👋
Предлагаем выполнить небольшое тестовое задание, которое поможет нам познакомиться с вашим подходом к разработке на Bitrix.
Ожидаемое время выполнения: около 2 часов.
Нам важно не только получить работающий результат, но и увидеть ваш подход к решению задач, структуру кода и использование возможностей Bitrix Framework.
1. Создание HL-блока «Оборудование»
Создайте HL-блок «Оборудование» со следующими полями:
•	UF_NAME — «Название», строка.
•	UF_TYPE — «Тип оборудования», список со значениями: 
o	Роутер
o	Ноутбук
o	Монитор
•	UF_CREATED_TIME — «Дата создания», дата/время.
•	UF_DEAL_ID — «ID сделки», число.
Наполните HL-блок тестовыми записями.
2. Создание смарт-процесса
Создайте смарт-процесс, который связан со сделкой.
Заведите тестовую сделку и элемент смарт-процесса, связанный с этой сделкой.
3. Разработка компонента для отображения оборудования
Создайте компонент на основе данных из HL-блока «Оборудование», используя:
•	main.ui.grid — для отображения таблицы;
•	main.ui.filter — для фильтрации данных.
Компонент должен отображать оборудование, привязанное к определённой сделке.
4. Добавление вкладки «Оборудование»
Добавьте вкладку «Оборудование» в карточку элемента смарт-процесса.
На вкладке должен отображаться созданный ранее компонент с фильтрацией по сделке, связанной с текущим элементом смарт-процесса.
5. Отображение количества оборудования в карточке сделки
В карточке сделки под полем «Клиент» добавьте отображение общего количества оборудования, привязанного к этой сделке из HL-блока «Оборудование».
Требования:
•	Поле должно быть неинтерактивным, то есть предназначенным только для отображения.
•	Для пользователя с ID 5 необходимо визуально выделить это поле.
Что ожидаем получить
По результатам выполнения задания, пожалуйста, предоставьте:
•	Пример кода компонента для отображения оборудования.
•	Код добавления компонента во вкладку смарт-процесса.
•	Код, реализующий отображение общего количества оборудования в карточке сделки.
•	Описание того, как подключается соответствующий скрипт.
Будет здорово, если код будет структурированным и понятным, а выбранные решения — обоснованными.
Если какой-то момент допускает несколько вариантов реализации, выбирайте тот, который считаете наиболее подходящим, и при необходимости кратко поясните свой выбор.
Спасибо за уделённое время! Удачи в выполнении задания! 🚀
